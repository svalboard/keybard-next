# Keybard bleeding edge

https://svalboard.github.io/keybard-next/ serves the tip of [svalboard/keybard](https://github.com/svalboard/keybard) `main`, rebuilt on every merge. It may break. The stable site is https://keybard.svalboard.com.

This repository holds no source. The `gh-pages` branch is overwritten by `svalboard/keybard`'s `next-deploy.yml` workflow on each merge, using this repository's deploy key. Don't commit to it by hand.
